# 📌 ĐỀ TÀI BÀI TẬP LỚN: QUẢN LÝ TÀI CHÍNH CÁ NHÂN (SPENDWISE)

## 1. Tên đề tài
**Hệ thống Quản lý Tài chính Cá nhân (SpendWise)**

## 2. Tên trang đã thực hiện
**Trang Giao Dịch (Transaction Dashboard)**

## 3. Mục đích của trang
Trang Giao dịch giúp người dùng theo dõi và quản lý dòng tiền cá nhân (thu nhập và chi tiêu), kiểm tra các khoản chi được đề xuất phân loại tự động bởi AI, lọc/tìm kiếm danh sách giao dịch nhanh chóng và cập nhật trạng thái kiểm duyệt các khoản chi.

## 4. Các chức năng chính
- **Hiển thị danh sách giao dịch:** Render dữ liệu động từ mảng JavaScript/JSON với định dạng tiền tệ VND và trạng thái rõ ràng.
- **Tìm kiếm Realtime:** Tìm kiếm nhanh theo tên giao dịch hoặc ghi chú ngay khi người dùng gõ từ khóa.
- **Lọc dữ liệu đa năng:** Lọc theo Tab (Tất cả, Khoản chi, Khoản thu, Chờ duyệt), theo Danh mục và Trạng thái.
- **Thêm giao dịch mới:** Mở/đóng Modal form, có Form Validation kiểm tra dữ liệu đầu vào và cập nhật danh sách tức thì.
- **Xác nhận phân loại AI:** Chọn giao dịch để xem chi tiết và chuyển trạng thái từ "Chờ duyệt" sang "Đã xác nhận".
- **Giao diện Responsive:** Hỗ trợ menu trượt Off-canvas trên Mobile, bảng tự động cuộn ngang và layout co giãn linh hoạt trên Desktop, Tablet, Mobile.

## 5. Công nghệ sử dụng
- **HTML5:** Cấu trúc Semantic HTML (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`, `<form>`, `<table>`).
- **CSS3:** Flexbox, CSS Grid, Media Queries (`1024px`, `768px`, `480px`) tối ưu Responsive.
- **JavaScript (ES6):** DOM Manipulation, Event Listeners (`click`, `input`, `submit`), Array Methods (`filter`, `unshift`, `forEach`).
- **Assets:** Logo, Icon SVG và Ảnh đại diện cá nhân được quản lý trong thư mục `assets/`.
